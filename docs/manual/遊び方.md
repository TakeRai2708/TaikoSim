# TakeTaiko 遊び方

TakeTaiko の遊び方と、設定ファイル（`Config` フォルダの中の `.json`）の中身の意味をまとめたものです。

設定はふつう、ゲームの中の**設定画面（F1）**で変えられます。ファイルを直接書きかえるのは、画面にない設定を変えたいときや、困ったときだけにしてください。

[TOC]

## 1. はじめに（曲の入れ方）

TakeTaiko は `.tja`（太鼓さん次郎・TJAPlayer3・OpenTaiko と同じ形式）の譜面で遊びます。

1. `TakeTaiko.exe` の横の **Songs** フォルダに、曲のフォルダを入れる（1曲 ＝ `.tja` と音源（`.ogg` など）が入ったフォルダ）
2. ジャンルに分けたいときは、ジャンルのフォルダを作って、その中に `box.def` を置く（くわしくは「7. 曲フォルダの決まり」）
3. ゲームを起動すると、曲を読みこみます。2回目からはキャッシュを使うので速くなります

!!! note "ポイント"
    - `box.def` の無い所にある曲は、選曲画面の「**未分類**」にまとまります
    - 設定 → 一般 の［Songs フォルダを開く］から、フォルダをすぐ開けます

## 2. 操作

### 太鼓（叩くキー）

最初の起動のときに、**左縁（カッ）・左面（ドン）・右面（ドン）・右縁（カッ）**の4つのキーを登録します。あとから 設定 → キー で変えられます。1つの場所に、いくつでもキーを登録できます。

2人プレイの右側（2P）のキーは **C（左カッ）・V（左ドン）・N（右ドン）・M（右カッ）**で固定です。

### メニューでの動き方

| 操作 | 動き |
|---|---|
| ドン | 決定 |
| カッ | カーソルを動かす（左カッ＝前・右カッ＝次） |
| Esc | 戻る（エントリー画面で押すと「終了しますか？」。最初は「いいえ」） |
| マウス | クリックでも操作できます |

### どこでも使えるキー

| キー | 動き |
|---|---|
| F1 | 設定を開く／閉じる |
| F11 | スクリーンショット（Screenshots フォルダに保存） |

### 選曲画面

| キー | 動き |
|---|---|
| F2 | 演奏オプションを開く |
| F3 | 曲を検索（文字・難易度・★・ジャンルでしぼりこみ） |
| F4 | お気に入りに入れる／外す |
| Tab | おにを選んでいるときに、裏おにに切り替え（おにで右カッを10回たたいても切り替わります） |
| カッを素早く2回 | 7曲とばし |

### 演奏中

| キー | 動き |
|---|---|
| F5 | クイックリスタート（最初からやり直し） |
| Esc | 一時停止メニュー（演奏を続ける／初めからやり直す／選曲画面にもどる）。段位道場では、やめて段位えらびに戻る |
| F3 | 曲の情報を出す（段位道場では「強制終了」） |

### 特訓モード

| キー | 動き |
|---|---|
| Space | 一時停止／再生 |
| ← → | 前の小節／次の小節（一時停止中） |
| ↑ ↓ | 再生の速さを変える |

キーはどれも 設定 → キー で変えられます（Esc だけは「戻る」で固定）。

## 3. 画面の流れとモード

**起動 → エントリー（1人／2人・データえらび）→ モードえらび → それぞれのモード**

### エントリー

- ドンで参加。もう片方の太鼓でもドンを叩くと2人プレイ
- データ（プレイヤー）は3つまで。初めて使うデータは名前を入れます（2つ目からのデータは、最初の起動と同じ初期設定もします）
- データごとに、記録・名前・着せ替え・音符の速さ・音量などが別々に保存されます

### モード

| モード | 内容 |
|---|---|
| 演奏ゲーム | ふつうに曲を遊ぶ。2人プレイもOK |
| 特訓モード | 好きな小節から練習できる（1人だけ） |
| 段位道場 | 3曲続けて演奏して、お題の合格を目指す（1人だけ）。段位のデータは TaikøNauts と同じ形式（`dan.def`・`dan.json`） |
| 着せ替え | どんちゃん・ぷちキャラ・ネームプレート・名前・称号・段位の表示を変える |
| 設定 | F1 と同じ |
| フィードバック | 不具合や意見を書いて送る（送り先は GitHub の画面） |
| クレジット | 使わせてもらっているもの |

## 4. 演奏オプション（選曲画面で F2）

| 項目 | 内容 |
|---|---|
| オート | 自動で叩く。オートの曲は記録に残りません |
| 音符の速さ | 音符が流れる速さ（見た目だけ。判定は変わりません） |
| オート連打 | オートのときの連打の速さ（1秒に何打） |
| 音色 | ドン・カッの音（HitSounds フォルダの中から選ぶ） |
| ドロン | 音符の絵が消える（下の文字だけ流れる） |
| あべこべ | ドンとカッを全部入れかえる |
| ランダム | ドンとカッをランダムに入れかえる（きまぐれ＝少し／でたらめ＝たくさん） |
| 演奏速度 | 曲そのものの速さ（0.5〜2.0倍。音の高さも変わります）。段位道場・2人プレイ・特訓モードでは使えません |
| ボイス | 演奏中のコンボの声を鳴らすか |
| 判定の板 | 演奏画面の左下に、良・可・不可・連打の数を出すか |

## 5. フォルダの中身（TakeTaiko.exe の横）

| フォルダ | 中身 |
|---|---|
| Songs | 曲を入れる所 |
| Skins | スキン（見た目と音のセット）。TaikoSim-Simple は最初から入っています |
| HitSounds | 音色（ドン・カッの音のセット） |
| Config | 設定と記録（「6. 設定ファイルの説明」） |
| Cache | 読みこみを速くするための一時ファイル。消しても大丈夫（次の起動で作り直します） |
| Logs | 起動ごとの記録（不具合を調べるとき用）。新しい10回分を残します |
| Screenshots | スクリーンショット |

!!! note "更新しても消えないもの"
    更新しても Songs・Config・自分で入れたスキン・HitSounds は消えません。

## 6. 設定ファイルの説明（Config フォルダ）

!!! warning "書きかえる前に"
    - どれも JSON という形式のテキストです。メモ帳で開けます
    - **ゲームを閉じてから**書きかえてください（開いたままだと上書きされます）
    - `"名前": 値,` の形を崩すと読めなくなります。カンマ（`,`）や `"` に気をつけて
    - おかしな値は、読みこむときに自動で直されます
    - ファイルを消すと、その設定は初期値にもどります（**記録のファイルは消さないで！**）
    - ON/OFF は `true`（ON）/ `false`（OFF）

### 6-1. GameConfig.json（ゲーム全体の設定）

「データごと」の印があるものは、6-5 の `PlayerSettings.json` の値が優先されます。

#### タイミング

| 名前 | 意味 | 値の例 |
|---|---|---|
| AudioOffsetMs | 音オフセット。判定のタイミングごとずらす。マイナスで早く、プラスで遅く。設定 → 演奏 の［タイミングを測る］で、叩いて決めることもできます | `0`（-150〜150 ミリ秒） |
| ChartOffsetMs | 譜面オフセット。音符の見た目の位置だけずらす（判定は変わらない） | `0`（-150〜150 ミリ秒） |

#### 画面

| 名前 | 意味 | 値の例 |
|---|---|---|
| UiTheme | UI の色。`Dark`（ダーク）か `Pink`（ピンク）。設定画面・初期設定・お知らせの色が変わる（ゲームの画面はスキンの絵なので変わらない） | `Dark` |
| WindowWidth / WindowHeight | ウィンドウの大きさ | `1280` / `720` |
| Fullscreen | フルスクリーンにするか | `false` |
| GraphicsBackend | 描画方式（変えたら再起動）。起動できなかったときは、次の起動で自動的に OpenGL にもどります | `"OpenGL"` / `"DirectX11"` / `"Vulkan"` |
| VSync | 垂直同期（ON でカクつきが減るかわりに、少し遅れます） | `false` |
| TargetFps | 目標のフレームレート（0 で無制限） | `60` |
| ShowFps | 画面の左上に FPS を出すか | `true` |
| FullscreenType | 使っていません（古い設定ファイルを読めるように残しているだけ） | — |

#### 入力

| 名前 | 意味 | 値の例 |
|---|---|---|
| InputTiming | 判定に使う打鍵の時刻。`"HighPrecision"`（高精度：押した時刻そのまま。おすすめ）／`"Compatible60Hz"`（16.67ms 刻みにそろえる。TaikøNauts 風の実験用） | `"HighPrecision"` |
| LimitDrumHitsTo60PerSecond | 4キー合計で1秒に60打までにするか | `false` |

#### 演奏（データごと）

| 名前 | 意味 | 値の例 |
|---|---|---|
| AutoPlay | オートで叩くか | `false` |
| HiSpeed | 音符の速さ（0 で譜面どおり。1.5 なら 1.5倍） | `0` |
| AutoRollPerSecond | オートの連打の速さ（1秒に何打。0 ならオートは連打しない） | `20`（0〜1000） |
| AutoGoodPercent / AutoOkPercent / AutoBadPercent | オートの 良・可・不可 の割合（%）。全部 0 なら全部良 | `100` / `0` / `0` |
| AutoFixedPattern | オートの良・可・不可の出方を、毎回同じにするか | `false` |
| HitSound | 音色（HitSounds フォルダの中のフォルダ名。空ならスキンの音） | `""` / `"Clap"` |
| ShowScoreboard | 演奏画面の左下に、良・可・不可・連打の板を出すか | `true` |
| Doron / Abekobe | ドロン・あべこべ | `false` |
| Random | ランダム | `"Off"`（しない）/ `"Kimagure"`（きまぐれ）/ `"Detarame"`（でたらめ） |
| PlaySpeed | 演奏速度 | `1`（0.5〜2.0） |
| ComboVoice | コンボの声を鳴らすか | `true` |
| RecordGroup | 王冠・ランクの数をどの難易度で数えるか | `"Easy"` / `"Normal"` / `"Hard"` / `"Oni"`（おにだけ）/ `"OniAndUra"`（おに＋裏） |

#### そのほか

| 名前 | 意味 | 値の例 |
|---|---|---|
| DebugMenu | 設定の「デバッグ」カテゴリを出すか | `false` |
| DebugPlayKeys | 演奏中のデバッグ用のキー（F3・F6・F7・F8・F10）を使うか | `true` |
| DebugLog | デバッグ記録（CSV）を取るか（重くなるので、調べるときだけ） | `false` |
| ShowPerfOverlay | 重さの内訳を画面の右上に出すか | `false` |
| ShowCursorPosition | マウスの場所の座標（1920×1080 として）を出すか | `false` |
| DiscordPresence | Discord の「プレイ中」に、今なにをしているか出すか | `true` |
| DiscordHideSongTitle | Discord に曲名を出さないか（ON なら難易度だけ） | `false` |

### 6-2. SoundConfig.json（音の設定）

#### 音量（0〜100、データごと）

| 名前 | 意味 |
|---|---|
| MasterVolume | 全体（ほかの全部にかかる） |
| SeVolume | 効果音（ドン・カッなど） |
| MusicVolume | 演奏中の曲・選曲画面のプレビュー |
| BgmVolume | メニューの BGM |
| VoiceVolume | どんちゃんの声 |

#### 音の出し方

| 名前 | 意味 | 値の例 |
|---|---|---|
| OutputType | 出力方式（下の表） | `"Bass"` |
| BassBufferMs | BASS・DirectSound のときのバッファ（ミリ秒、0 で自動）。小さいほど遅れが減るけど、小さすぎると音がブツブツ切れます | `15` |
| WasapiBufferMs | WASAPI のときのバッファ（ミリ秒、0 で自動） | `50` |
| AsioDevice | ASIO のときに使う機器の番号（0 から） | `0` |

| OutputType の値 | 内容 |
|---|---|
| `"Bass"` | 標準。ふつうはこれ |
| `"DirectSound"` | 昔の方式。うまく鳴らないとき用 |
| `"WasapiShared"` | WASAPI 共有。ほかのアプリの音も一緒に鳴る |
| `"WasapiExclusive"` | WASAPI 排他。遅れが少ないかわりに、ほかのアプリの音が鳴らなくなる |
| `"Asio"` | ASIO。対応した機器が必要。いちばん速い |

### 6-3. KeyConfig.json（キーの設定）

| 名前 | 意味 |
|---|---|
| DrumKeys | 叩く場所ごとのキー（いくつでも登録できる）。例：`"LeftDon": [ "F" ]` |
| SystemKeys | 役割ごとのキー（1つずつ） |

| 叩く場所 | 意味 |
|---|---|
| LeftKa / LeftDon / RightDon / RightKa | 1P の左縁・左面・右面・右縁 |
| P2LeftKa / P2LeftDon / P2RightDon / P2RightKa | 2P（C・V・N・M で固定） |

| 役割 | 意味 | 初期のキー |
|---|---|---|
| Settings | 設定 | F1 |
| QuickRestart | やり直し | F5 |
| QuickOption | 演奏オプション | F2 |
| Screenshot | スクリーンショット | F11 |
| Search | 検索 | F3 |
| Favorite | お気に入り | F4 |
| TrainingPause | 特訓の一時停止 | Space |
| TrainingPreviousBar / TrainingNextBar | 特訓の前の小節／次の小節 | ← / → |
| TrainingFaster / TrainingSlower | 特訓の速さ | ↑ / ↓ |

- キーの名前は `"F"`、`"Space"`、`"Left"`、`"F1"` のような書き方です
- Esc は「戻る」で固定。ほかの役割には使えません
- 同じキーを2つの役割に使うと、読みこむときに片方が外されます

### 6-4. SkinConfig.json（どのスキンを使うか）

| 名前 | 意味 | 値の例 |
|---|---|---|
| SkinsFolder | スキンが入っているフォルダの場所（空なら exe の横の Skins） | `"D:\\TaikoSkins"`（`\` は2つ重ねて書く） |
| SkinName | 使うスキンのフォルダ名 | `"TaikoSim-Simple"` |

設定 → スキン で選んで［スキンを適用］を押すと、ここに書かれます。

!!! note "スキンのフォルダの中の SkinConfig.json（スキンを作る人用）"
    | 名前 | 意味 |
    |---|---|
    | skinName / skinVersion / skinDescription | 表示名・版・説明 |
    | mainFont | 曲名・名前の太い字のフォント |
    | systemFont | 設定画面などのふつうの字のフォント |
    | detailFontPath | 細かい数字の字のフォント |

    フォントはスキンのフォルダからの場所で書きます（例：`"Font/MyFont.otf"`）。使えるのは `.ttf` と `.otf` だけです。

### 6-5. プレイヤーデータ（PlayerData フォルダ）

`Config\PlayerData\1`・`2`・`3` が、データ（プレイヤー）ごとのフォルダです。

#### NamePlateConfig.json（ネームプレート）

| 名前 | 意味 | 値の例 |
|---|---|---|
| name | 名前 | `"たけらい"` |
| title | 称号（プレートの上に出る文字） | `""` |
| rank | 段位の表示。段位道場に合格すると自動で書きかわります | `"六段"` |
| isRankGold | 段位の字を金色にするか（金合格） | `false` |
| rankType | 段位の飾り | `0`（銀）/ `1`（金）/ `2`（虹） |
| namePlateId | プレートの絵の番号（スキンの NamePlate\Plates の中のフォルダ名）。空ならおまかせ（1P は 02、2P は 03） | `""` / `"00"` |

着せ替えでは、合格したことがある段位だけ選べます。ここを直接書きかえると何でも出せます。

#### PlayerConfig.json（着せ替え）

| 名前 | 意味 |
|---|---|
| donchanId / donchanType | どんちゃんの種類 |
| isUsePuchiChara | ぷちキャラを出すか |
| puchiCharaId | ぷちキャラの種類 |

#### PlayerSettings.json（データごとの設定）

6-1・6-2 で「データごと」と書いたもの（音符の速さ・音色・オート・ドロンなど・音量）。このデータで遊んでいる間は、こっちの値が使われます。

### 6-6. SongHistory.json（記録）

- データ1は `Config\SongHistory.json`、データ2・3は `Config\PlayerData\2（3）\SongHistory.json`
- 中身：曲ごと・難易度ごとのベストスコアと王冠、段位の合格、最近遊んだ曲、お気に入り

!!! danger "このファイルは書きかえたり消したりしないで！"
    記録が全部消えます。バックアップしたいときは、ゲームを閉じてからコピーしてください。

## 7. 曲フォルダの決まり（box.def・ジャンル）

- `box.def` があるフォルダが、選曲画面の「**ジャンル**」になります
- `box.def` のフォルダの中にある曲は、もっと奥のフォルダにあっても、そのジャンルに入ります
- `box.def` の中の、さらに奥の `box.def` は使いません
- `box.def` の無い所の曲は「**未分類**」に入ります
- `dan.def` / `dan.json` があるフォルダは段位道場用。選曲画面には出ません

| box.def に書くこと | 意味 |
|---|---|
| `#TITLE:J-POP` | 選曲画面に出るジャンルの名前（無ければフォルダ名） |
| `#GENRE:J-POP` | ジャンルの種類（色や、スキンの板の絵が決まる） |
| `#BACKCOLOR:#1E90FF` | 板の色を自分で決めたいとき |
| `#BOXTYPE:1` / `#BGTYPE:1` | スキンの板・背景の絵の番号（TaikøNauts と同じ） |

## 8. スキン・音色の入れ方

### スキン

1. Skins フォルダに、スキンのフォルダを入れる（TaikøNauts のスキンと同じ形）
2. 設定（F1）→ スキン で選んで［スキンを適用］

- 別の場所にあるスキンを使うときは［フォルダ選択］で場所を指定できます
- 新しく入れたスキンが一覧に出ないときは［スキン一覧を更新］

### 音色

1. HitSounds フォルダに、音色のフォルダを入れる
    - 中身：`dong.ogg`（または `don.ogg`）と `ka.ogg`、名前を書いた `HitSounds.json`
    - OpenTaiko の `Global\HitSounds` と同じ形なので、そのまま入れられます
2. 演奏オプション（F2）の「音色」で選ぶ

## 9. 困ったとき

### 音と判定がずれる

- 設定 → 演奏 の［タイミングを測る］で、メトロノームに合わせて叩くと、合う音オフセットを測ってくれます
- それでも合わないときは、設定 → 音 の出力方式やバッファを変えてみてください

### 起動しない・すぐ落ちる

- Logs フォルダの一番新しいフォルダの `System\TaikoSim.log` を見てください（不具合を報告するときは、このファイルを送ってもらえると助かります）
- 描画方式で起動できなかったときは、次の起動で自動的に OpenGL にもどります

### 曲が出てこない

- Songs の中に `.tja` が入っているか確かめてください
- Cache フォルダを消して起動しなおすと、曲を全部読みなおします

### 設定をおかしくしてしまった

- ゲームを閉じて、Config フォルダの `GameConfig.json`・`SoundConfig.json` などを消すと、初期値にもどります
- 記録の `SongHistory.json` と `PlayerData` フォルダは消さないでください
