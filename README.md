# TakeTaiko

TakeTaiko は、Windows で遊べる太鼓シミュレーターです。手持ちの TJA 譜面を追加して遊べます。

## ダウンロードとインストール

**[TakeTaikoSetup.exe をダウンロード（Windows 64 ビット）](https://github.com/TakeRai2708/TaikoSim/releases/latest/download/TakeTaikoSetup.exe)**

1. ダウンロードした `TakeTaikoSetup.exe` を開きます。
2. **「参照…」** で保存先を選びます。画面に実際のインストール先が表示されます。
3. デスクトップから開きたい場合は **「デスクトップにショートカットを追加」** にチェックします。**「インストール」** を押すと、ゲーム本体と必要なファイルがダウンロードされます。
4. 完了画面で **「はい」** を押すと TakeTaiko が起動します。あとで遊ぶときは、スタートメニューの **TakeTaiko** またはインストール先の `TakeTaiko.exe` を開きます。

インストールにはインターネット接続が必要です。GitHub アカウントは不要です。

## 譜面を追加する

1. ゲーム内の設定を開き、**「Songs フォルダを開く」** を押します。
2. 開いたフォルダーに、`.tja` と音源が入った曲フォルダーを置きます。
3. ゲームに戻って **「曲の一覧を更新」** を押し、選曲画面から曲を選びます。

## 更新する

`TakeTaiko.exe` を開くと、ゲームが最新版を確認します。更新が見つかったら、内容を読んで **「はい」** を押すとダウンロードと再起動が始まります。**「いいえ」** を押せば、そのまま遊べます。更新時も設定や追加した譜面は残ります。
