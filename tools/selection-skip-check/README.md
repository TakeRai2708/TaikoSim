# 同方向3連打のスキップ判定

.NET 10 SDKがあれば、外部パッケージ・Raylib・BASSなしで実行できます。

```sh
dotnet run --project tools/selection-skip-check/Check.csproj
```

実際のSongSelectSkipGesture.csをコンパイルし、左右3連打、2打では発動しないこと、250ms境界、左右混在、交互打ち、遅い連打、直近3打、発動後のリセットを41項目で確認します。

3打目までの時間は最初の打鍵から250ms以内です。各打鍵間隔が250ms以内という意味ではありません。
このチェックは連打を数える部分のみ。0.5秒ロック、実キー入力・クリック・音声・描画はWindowsで別途確認してください。

追加時の作業環境にはSDKがなく、このチェック・本体ビルド・Windows実機確認は未実施です。
